## p5.js

Copyright the p5.js contributors / Processing Foundation. p5.js is free software distributed under GNU LGPL 2.1; see the exact upstream license texts included below. There is no warranty. The artwork source is not relicensed by this notice.

The eight artwork folders contain unmodified p5.min.js distributions. Versions:
- 1.4.1: Recursive and Blocks, Generative Succulent, Human Flow, Refractions, Zen Pots.
- 1.5.0: Folding, Sketching Clouds, Wire City.

For each version, third-party/p5-VERSION/ includes:
- license.txt: upstream LGPL 2.1 license.
- p5.js: matching readable distribution, including bundled component notices.
- UPSTREAM-README.md: original attribution and project information.
- source.tar.gz: complete upstream tagged repository source, including source modules, package/dependency metadata and build instructions. These archives are source data, not runtime code; nothing is extracted or executed by the player.

The library is unchanged and can be replaced in each artwork folder. Its copyright and bundled component notices remain in the readable distribution and complete upstream archive. Components retain their respective licenses; refer to the corresponding source notices.

Sources:

- https://cdn.jsdelivr.net/npm/p5@1.5.0/lib/p5.js
